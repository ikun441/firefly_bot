## 当前实现

| 功能 | 行为 |
| --- | --- |
| 账套与科目 | 多个独立 CNY 账套、月初启用；新增/编辑/查询/切换/归档/恢复；科目支持父子层级与数量单价核算 |
| 预算 | 新建、编辑、停用费用类别，按月设置额度；费用凭证选择类别；仅已过账费用计入执行，冲销抵减 |
| 工作台与日志 | 摘要/科目/借贷工作表，上下保存入口；中文校验，无原始 JSON；统一中文操作日志含操作人及平台 |
| 金额 | API 十进制字符串、数据库整数分，拒绝浮点、超精度、非有限与越界金额 |
| 期初 | 唯一 opening 凭证审核过账核定，或明确确认全零期初；不计本期损益及现金流 |
| 凭证 | 草稿→提交→审核→过账；可驳回、撤回、撤销审核、作废未过账凭证 |
| 不可变与更正 | 数据库保护已过账头/分录；普通凭证可申请一次完整红字冲销，仍需审核过账 |
| 并发与幂等 | SQLite BEGIN IMMEDIATE 在读取状态前串行化，版本、期间、编号、审计与回执同事务 |
| 查询 | 借贷汇总、科目余额、试算、凭证明细；网页与 QQ 共用日期过滤 |
| 财务汇总 | 资产负债权益、收入费用利润、经营/投资/筹资现金流；资金分类缺失时不输出完整现金流 |
| 对账 | 手工资金余额与未达项调节；新增过账即使净额为零也会使原对账失效 |
| 结账 | 月度/年度结转草稿、过账再核对余额；检查前期、草稿、对账与勾稽后关账，保存快照 |
| 业务入口 | QQ 15 分钟预览确认、网页草稿、CSV/XLSX 导入；只保存业务事实，不自动过账 |
| 权限与审计 | 唯一管理员、QQ 独立 CRUD、实时检查、实际账号与平台留痕；superusers/推送目标不自动授权 |
| AI | 只读财务汇总、科目余额、凭证、科目明细工具；账套和身份由服务端决定，无 SQL/写账工具 |
| 图片 | 帮助、明细、报告和 AI 回复渲染 Markdown 图片，长文分页，失败回退文字 |
| 备份 | v3 JSON 覆盖旧表及多账套、层级科目、数量分录、费用预算、权限、会话、对账和审计；兼容完整 v2 会计备份恢复，含数量、结构版本与 SHA-256 |
| 恢复 | 只恢复到新隔离库，检查模型字段、外键、编号、冲销、试算及 SQLite 完整性；拒绝覆盖 |
| 历史兼容 | 新账启用后阻断旧流水/导入/订阅写账，暂停旧自动报告/预警，旧还原/升级不能覆盖新账 |

新核算接口位于 /api/v2。始终要求管理员登录，旧 auth.enabled=false 不再关闭鉴权。

## QQ 周期查询

默认本月，按配置时区计算，起止日均包含。明细包含凭证状态，报告只汇总已过账分录。

| 示例 | 解释 |
| --- | --- |
| /明细 | 本月至今天，第 1 页，每页 10 张 |
| /明细 上月 第2页 | 上一个完整自然月的第 2 页 |
| /明细 2026-11 | 指定自然月 |
| /明细 2026-11-01 2026-11-07 | 自定义日期范围 |
| /报告 本周 | 本周一至今天 |
| /报告 上季度 | 上个完整自然季度 |
| /报告 2026 | 指定自然年 |
| /报告 2026-11-01 至 2026-11-30 | 自定义期间 |
| ai 本月利润是多少？为什么利润与现金增加不同？ | 新账只读查询与分析 |

支持今天/昨天、本周/上周、本月/上月、本季度/上季度、本年/去年、YYYY、YYYY-MM、YYYY-MM-DD 与起止日期。/明细 可在末尾附“第N页”。非法日期、倒置范围与非法页码明确拒绝。帮助图片包含以上用法。

## 操作与恢复

1. 管理员登录，在权限设置绑定管理员 QQ、添加普通 QQ 并授权。
2. 创建账套并核定期初；根据原始资料人工判断科目，保存借贷平衡的凭证。
3. 提交、管理员审核、过账；草稿和审核态不影响正式余额。
4. 月末逐个资金科目对账、结转损益、预检与结账；12 月另做年度利润结转。
5. 下载完整备份，独立妥善保存配置与密钥。

恢复命令（不切换服务）：

    python scripts/restore_backup.py /path/to/backup.json --database /path/to/new-isolated.db

目标目录须存在，数据库文件须尚不存在。成功后仍需停止写入、核对隔离库，再按维护流程切换配置。v1 备份需在旧版隔离环境恢复并核对承接，不能覆盖会计账。
